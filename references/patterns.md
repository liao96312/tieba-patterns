# Tieba Pattern 参考库

贴吧句式库 - 108 类 Pattern

> 本文件保留桌面原稿的句式分类与例子。生成回复时必须遵守上级 `SKILL.md` 的边界；越界例子只借用修辞结构，不照抄目标或伤害内容。

## 使用指南

### 四步法
1. **解析语义** — 解构对方信息，寻找逻辑漏洞
2. **备选语料** — 从句式库找出可选 Pattern
3. **语气风格** — 暴躁或阴阳怪气，有攻击性
4. **精炼输出** — 一句到位 > 十句复读

### 核心战术
- **永远不自证** — 永远是别人的错
- **找漏洞放大** — 抓住对方错误扩大
- **道德制高点** — 审判对方
- **反客为主** — 把攻击转为素材

## Pattern 分类速查

### 1. 外貌/能力羞辱
**Pattern**: [人]长这b样[对象]怎么看上他的
- 原句：李荣浩长这b样杨丞琳怎么看上他的
- 拓展：王思聪长这b样那些网红怎么看上他的

- 拓展：本鼠准备出击了，等女神上线看我🔥速舔爆

## 使用原则

1. **不生搬硬套** — 必须建立在对方具体言行上
2. **宁要一句到位** — 不要十句空洞复读
3. **避免高频词重复** — 保持新鲜感
4. **逻辑 > 黑话** — 黑话是调料，逻辑是主菜
5. **永不自证** — 永远是别人的错
